# 🌡️ Conversor de Temperatura e Sistema de Boas-Vindas

Este notebook contém um conjunto de funções práticas em Python para interagir com o usuário e realizar conversões de temperatura entre diferentes escalas (°C, °F e K).

## 🚀 Funcionalidades

### 1. Sistema de Boas-Vindas (`boas_vindas` / `boas_vindas_usuario`)
*   **`boas_vindas()`**: Interage diretamente com o usuário no console, solicitando o nome e exibindo uma mensagem personalizada.
*   **`boas_vindas_usuario(usuario)`**: Recebe um nome como parâmetro e exibe uma saudação direta.

### 2. Conversão de Temperatura
*   **`celcius_f(temperatura)`**: Converte uma temperatura em graus Celsius (°C) para Fahrenheit (°F).
    *   *Fórmula:* $F = (C \times 1.8) + 32$
*   **`celcius_k(temperatura)`**: Converte uma temperatura em graus Celsius (°C) para Kelvin (K).
    *   *Fórmula:* $K = C + 273$
